Integrating the relay into a Luma3DS fork
==========================================

New files (drop into the Luma3DS tree):
  sysmodules/rosalina/source/nwm_relay.c
  sysmodules/rosalina/include/nwm_relay.h
  sysmodules/rosalina/source/menus/nwm_relay_menu.c
  sysmodules/rosalina/include/menus/nwm_relay_menu.h
  sysmodules/rosalina/include/vps_config.h        (copied from vps_config.h.example)

Everything else is a small edit to an existing file.


k11_extension/include/globals.h
  Add near the other externs:
    extern volatile bool nwmRelayEnabled;   // 0 = stock nwm behaviour
    extern volatile u32  nwmRelayPid;        // the relay's pid, exempt from the redirect

k11_extension/source/globals.c
  Add:
    volatile bool nwmRelayEnabled = false;
    volatile u32  nwmRelayPid = 0xFFFFFFFF;

k11_extension/include/svc/ControlService.h
  Add to the ServiceOp enum (keep the values):
    SERVICEOP_REGISTER_RELAY_PID = 4,   // called by the relay: records its pid
    SERVICEOP_SET_RELAY_ENABLED  = 5,   // varg1 = 0/1

k11_extension/source/svc/ControlService.c
  Add two cases to ControlService():
    case SERVICEOP_REGISTER_RELAY_PID:
        nwmRelayPid = idOfProcess(currentCoreContext->objectContext.currentProcess);
        return 0;
    case SERVICEOP_SET_RELAY_ENABLED:
        nwmRelayEnabled = (varg1 != 0);
        return 0;

k11_extension/source/svc/SendSyncRequest.c
  In case 0x50100 (srv:GetServiceHandle), right after the requested service name is
  copied into `name`, rewrite nwm::UDS to the relay for everyone but the relay itself:
    if(nwmRelayEnabled && pid != nwmRelayPid && strcmp(name, "nwm::UDS") == 0)
    {
        memcpy(cmdbuf + 1, "nwmrelay", 8);
        memcpy(name, "nwmrelay", 8);
    }


sysmodules/rosalina/source/main.c
  #include "nwm_relay.h"

  In main(), after the other threads:   nwmRelayCreateNetThread();
  At the very start of handlePreTermNotification(), before miniSocUnlockState():
    g_netStop = true;
    for(int i = 0; i < 50 && !g_netStopped; i++)
        svcSleepThread(5 * 1000 * 1000LL);
